How to remove data from Bharat Joy games on Android. Effective date: 12 November 2026.

There is no account to delete

Our games do not have sign-in, cloud saves or a game server. Your name, picture, optional gender, coins and progress are kept only on your phone. This page covers:

  • Bharat Ludo (भारत लूडो), package com.bharatjoy.ludo
  • Bharat Block Puzzle (भारत ब्लॉक पहेली), package com.bharatjoy.blockpuzzle
  • Bharat Sweet Mela (भारत स्वीट मेला), package com.bharatjoy.sweets

Delete everything the game saved

Do either of these on your phone:

  1. Uninstall the game. This removes all of its saved data.
  2. Or open Settings, then Apps, choose the game, then Storage, and tap Clear storage (on some phones, Clear data). The game starts fresh next time.

We cannot restore this data after it is removed, because we never had a copy.

Advertising ID

Ads come from Google AdMob, which uses your phone's advertising ID. To delete or reset it, open Settings, then Google, then Ads, and choose Delete advertising ID (or Reset advertising ID on older Android versions). Google handles ad data under its own privacy policy.

Usage events in Bharat Ludo

Bharat Ludo sends anonymous usage events to Google Firebase Analytics, linked to a random app-instance ID and not to your name. Uninstalling or clearing storage removes that ID from your phone, so older events are no longer linked to it. Google keeps those events only for the retention period set for the project, and then deletes them. If you would like us to ask for them to be deleted sooner, write to us.
